# Design Portfolio & Visual Assets

This repository holds a collection of my graphic design and UI/UX work. Everything here represents practical design projects, interface layouts, and branding assets I have built or worked on.

## What is Inside

- **UI/UX & Web Layouts:** Clean wireframes, responsive interface designs, and component libraries structured for web and mobile projects.
- **Branding & Visual Identity:** Logos, color palettes, typography pairings, and visual collateral created for various projects.
- **Graphic Assets:** Banners, social media graphics, promotional materials, and vector illustrations.

## Tools & Software

- **Figma:** Primary tool for UI design, wireframing, and layout prototyping.
- **Design Systems:** Component-driven organization, auto-layout structures, and style guides.
